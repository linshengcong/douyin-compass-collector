# 淘宝、抖音独立运行验收

验收日期：2026-10-02 至 2026-10-03。启动入口保持：

```bash
# 分别在两个终端启动，默认打开GUI、立即force采集、启用钉钉通知。
make run PLATFORM=tb
make run PLATFORM=tt
```

## 实现结果

- 配置解析后选择唯一平台，再将该平台数据库路径传入现有存储调用链。多平台配置必须声明各自的 `database_path`；旧单平台配置仍支持顶层 `database.path`。
- 数据库以 `runtime_platform` 单行记录平台归属，初始化、迁移及认领受数据库文件锁保护。混合历史、错误归属及配置中重复数据库/Profile路径拒绝启动；业务写入再次核验归属。
- GUI、采集、Scheduler锁分别位于 `runtime/locks/<platform>/`，Profile资源锁使用规范化路径的哈希。采集锁覆盖Chrome保留检查期；旧全局锁被占用时拒绝启动。
- 日志和Scheduler控制文件分别位于 `runtime/logs/<platform>/`、`runtime/controls/<platform>/`，Scheduler停止请求继续绑定实例UUID。
- 数据清理只处理所选平台，CLI必须显式指定平台；旧日期/task目录需Manifest证明归属，共享历史日志保留。
- 默认GUI、立即采集、force及通知行为保持；normal、重复商品与补录TODO语义保持。

## GUI验收与实际限制

使用两个独立进程运行生产GUI及真实Chrome；Qt界面离屏渲染，Chrome正常可见。验证各自平台标题、任务、日志、进度及结果展示。两轮正常关闭复验分别覆盖淘宝先关闭、抖音先关闭，另一平台仍继续工作；结束后两平台采集锁均可重新获取。

补充GUI试采的淘宝结果没有全部通过：

- 第一轮淘宝在每页20条确认阶段超时，抖音完成20页。两边Chrome关闭后Playwright驱动仍等待，验收进程未自然退出；仅结束本次两个残留驱动后资源释放。后续两轮正常关闭没有复现，尚未定位该偶发等待的根因，不能称为已修复。
- 跨午夜的香氛贴类目返回 `invalid_page_result`；另换空气芳香剂类目，保存5/11页后因实时榜总数变化触发既有 `inconsistent_total` 规则，终止且没有正式发布。没有修改这些采集业务规则。
- 抖音在上述失败期间独立完成；淘宝失败不影响另一平台的运行、关闭或锁释放。

证据：`runtime/acceptance/taobao/2026-10-02/platform-parallel-gui/summary.json`、对应平台日志、GUI截图及raw/失败材料。该目录保存最后一轮复验，前两轮异常保留在对应业务日期的SQLite批次及失败材料中。

## Make首次启动参数冲突修复

2026-10-03用户运行 `make run PLATFORM=tt` 时，Qt报找不到 `compass` 插件。业务CLI的 `--platform compass` 被 `QApplication(sys.argv)` 再次解析为Qt插件参数。此前GUI验收脚本预先创建Qt应用，漏掉了首次启动路径。

三处GUI/桌面提示初始化统一使用仅包含程序名的Qt参数，保留业务CLI参数。新增独立进程测试覆盖run/app、桌面终端提示、缺配置提示，以及compass/taobao两平台，检查可用插件与原始参数保持。通过真实Make/CLI入口分别打开两平台原生cocoa窗口，再正常关闭；该启动检查使用 `START=no NOTIFY=no`，没有执行新的正式采集或发送通知。

## GUI退出阻塞修复

2026-10-03现场日志显示两平台已中止采集且通知完成，Chrome已退出，GUI工作线程与Playwright驱动仍占用锁。关闭链路先等待 `context.close()` 的SDK事件，之后才执行驱动停止；关闭事件丢失时前一步没有超时，后一步无法执行。

通过本地真实Chrome故障注入移除context关闭通知，复现窗口不能退出。修复为先保存会话Cookie，再由该窗口自己的Playwright驱动正常关闭其浏览器资源并等待退出；不先等待context关闭事件。相同故障注入在修复后可正常结束。该试验验证阻塞机制，不证明现场SDK为什么漏收事件。

同时修复退出状态：确认退出后重复点击不再弹框，迟到的检查就绪事件不能恢复人工等待；同一窗口拥有采集和Scheduler时，退出一次同时请求两者收尾，只寻址本窗口的Scheduler实例。

完整后端回归591项通过、19项跳过；另行执行真实本地Chrome回归4项通过，包含关闭通知丢失后的Profile立即重开、持久Cookie和会话Cookie保留。两平台GUI真实退出试采证据位于 `runtime/acceptance/taobao/2026-10-03/gui-close/`，使用独立验收数据库，关闭通知与发布。
